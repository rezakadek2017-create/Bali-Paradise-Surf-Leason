# Bali-Paradise-Surf-Leason

Website & WordPress Theme for **Bali Paradise Surf Lesson**, Seminyak, Bali.

## 🏄‍♂️ Features
- Fully responsive modern design with Bali surf vibes
- Interactive lesson packages & booking via WhatsApp
- Embedded Google Maps with beach locations
- Photo & video gallery with interactive lightbox
- Fast, optimized static export ready for Vercel deployment
- WordPress theme included

## 🚀 Live Preview / Vercel Deployment
This repository is ready to be deployed directly on [Vercel](https://vercel.com).
The static landing page is powered by `index.html` and assets in `/bali-paradise-surf/assets/`.
